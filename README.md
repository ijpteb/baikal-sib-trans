# Сайт ООО «Байкал Сиб-Транс» (Иркутск)

Аренда автобусов, микроавтобусов и легковых автомобилей с водителем, пункт техосмотра.

**Посмотреть сайт:** https://ijpteb.github.io/baikal-sib-trans/

Это копия для просмотра: страницы и форма заявки в ней работают, а админка — нет
(для админки нужен хостинг с PHP). Как запустить сайт на своём компьютере и выложить
его на хостинг — в инструкции [README-RU.md](README-RU.md).

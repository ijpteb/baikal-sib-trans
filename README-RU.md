# Сайт «Байкал Сиб-Транс» — инструкция

Сайт ООО «Байкал Сиб-Транс» (Иркутск): пассажирские перевозки с водителем и станция техосмотра.
Всё содержимое сайта — тексты, автопарк, фото, цены, контакты, вопросы и ответы — меняется в админке, без программиста.

**Как это устроено, коротко**

- Посетитель выбирает поездку и транспорт, нажимает «Отправить заявку» — и отправляет её **сам**: звонком или сообщением в MAX (Telegram и WhatsApp — если включите их в админке).
- Сайт заявки не хранит и никуда не пересылает: нет базы клиентов, почтовых рассылок и онлайн-оплаты.
- Админка открывается по адресу сайта с `/admin` на конце, например `https://baikalst.ru/admin`.
- Сайту хватает обычного недорогого хостинга с PHP 8.1 или новее. База данных — один файл, отдельный сервер баз данных не нужен.

## 1. Что лежит в папке проекта

| Папка или файл | Что это |
|---|---|
| `app` | Программа сайта. Из интернета закрыта. |
| `data` | База данных `site.sqlite`: все тексты, автопарк, цены, логин администратора. **Самое ценное.** |
| `public` | То, что открывается в интернете: страницы, картинки, шрифты и загруженные фото (`public/uploads`). На хостинге эта папка называется `public_html`. |
| `Запустить сайт.command` | Запускает сайт на этом компьютере для проверки. |
| `Собрать архив для хостинга.command` | Собирает архив `baikal-site.zip` для загрузки на хостинг. |
| `README-RU.md` | Эта инструкция. |

Скрытые папки `.git` (история изменений) и `.claude` (настройки для Claude) — служебные, на хостинг их загружать не нужно.

## 2. Посмотреть сайт на своём компьютере

1. Дважды щёлкните файл **«Запустить сайт.command»**.
2. Откроется окно «Терминала», а через пару секунд — браузер с сайтом по адресу **http://localhost:8000**.
3. Админка — **http://localhost:8000/admin**.
4. Чтобы остановить сайт, закройте окно «Терминала».

Для запуска нужна бесплатная программа **Docker Desktop** (docker.com) или установленный PHP 8.1+. Самый первый запуск через Docker занимает пару минут.

Если macOS пишет, что файл нельзя открыть: щёлкните по нему правой кнопкой мыши → «Открыть» → ещё раз «Открыть».

Всё, что вы заполните в админке на своём компьютере, можно потом перенести на хостинг (раздел 4). А можно сразу заполнять на хостинге — как удобнее.

## 3. Какой хостинг выбрать

Нужен обычный **виртуальный хостинг** с PHP 8.1 или новее (лучше 8.3–8.4). Подходят оба популярных российских хостинга:

| | **Timeweb** — рекомендуем | Beget |
|---|---|---|
| Что заказывать | «Виртуальный хостинг» на timeweb.com (не Timeweb Cloud — это другая компания) | «Виртуальный хостинг» на beget.com |
| Тариф | Optimo: 729 ₽ в месяц, или 510 ₽ в месяц при оплате за год | Blog: 520 ₽ в месяц, или 420 ₽ в месяц при оплате за год |
| Бесплатный период | 10 дней | 30 дней |
| Свои резервные копии | каждую ночь, хранятся 30 дней | раз в 3–4 дня |

Цены — на 23 ноября 2026 года. Перед оплатой проверьте их на сайте хостинга.

**Почему Timeweb.** В начале ноября 2026 года Beget пострадал от серьёзной кибератаки: восстановление шло несколько недель, часть клиентов потеряла изменения за последние дни. Если всё же выберете Beget — платите помесячно, а не за год, и регулярно скачивайте резервную копию из админки (раздел 10).

**До оплаты**, в бесплатный период, загрузите сайт и откройте админку. На её главной странице есть блок **«Сервер и безопасность»** — он покажет, всё ли в порядке: версия PHP, обработка фото, HTTPS, защита папок.

## 4. Загрузка на хостинг (Timeweb, по шагам)

**Шаг 1. Регистрация.** Откройте timeweb.com/ru/services/hosting → на карточке тарифа нажмите «Начать бесплатно» → заполните форму. Логин и пароль от панели придут на почту. Панель управления — **hosting.timeweb.ru**.

**Шаг 2. Создайте сайт.** «Сайты» → «Мои сайты» → «Создать сайт» → имя папки: `baikalst.ru` → создать. Появится папка `baikalst.ru`, а в ней — `public_html`.

**Шаг 3. Версия PHP.** Наведите мышь на новый сайт → значок шестерёнки → «Настройки версии и кодировки» → «Настроить» → выберите **PHP 8.4** (если её нет в списке — 8.3) → «Сохранить». Переключатель «Изолировать сайт» оставьте включённым.

**Шаг 4. Соберите архив.** На своём компьютере дважды щёлкните файл **«Собрать архив для хостинга.command»**. Рядом с папкой проекта появится файл **baikal-site.zip** — Finder сразу его покажет.

- Если вы уже заполняли сайт на своём компьютере, в архив попадут все тексты, автопарк, фото, а также логин и пароль от админки.
- Если нет — сайт на хостинге начнётся с заготовок, а админка при первом входе попросит код (раздел 6).

**Шаг 5. Загрузите архив.** «Файловый менеджер» → откройте папку `baikalst.ru`:

1. Зайдите в `public_html` и удалите всё, что там лежит (обычно это страница-заглушка `index.html`). Вернитесь в папку `baikalst.ru`.
2. «Загрузить» → выберите файл `baikal-site.zip`.
3. Щёлкните по архиву правой кнопкой → «Извлечь» (или «Разархивировать») → в текущую папку.
4. Удалите `baikal-site.zip` — он больше не нужен.

Должно получиться так:

```
baikalst.ru/
├── app/            ← программа сайта
├── data/           ← база данных
└── public_html/    ← сайт для интернета: index.php, .htaccess, assets, uploads
```

Важно: папки `app` и `data` лежат **рядом** с `public_html`, а не внутри неё. Так база данных недоступна из интернета.

**Шаг 6. Проверьте сайт до переноса домена.** Timeweb бесплатно даёт технический адрес вида `ваш-логин.tw1.ru`. «Сайты» → у нового сайта значок глобуса → «Привязать» технический домен (если он привязан к «Основному сайту», сначала нажмите там «Отвязать»). Откройте `ваш-логин.tw1.ru` — должен открыться новый сайт.

**Шаг 7. Войдите в админку:** `ваш-логин.tw1.ru/admin` → дальше — раздел 6.

**Шаг 8. Оплатите хостинг** до конца бесплатного периода, когда убедитесь, что всё работает.

## 5. Если выбрали Beget

Порядок тот же, отличаются названия в панели (панель управления — **cp.beget.com**):

- **Регистрация:** beget.com/ru/hosting → тариф Blog → «Попробовать бесплатно».
- **Сайт:** «Сайты» → «Управление сайтами» → поле «Имя сайта»: `baikalst.ru` → «Создать».
- **PHP:** там же, значок шестерёнки рядом с сайтом → версия **8.4** (если её нет — 8.3). PHP 8.1 и 8.2 не выбирайте: они уже не получают исправлений безопасности или скоро перестанут.
- **Загрузка:** «Файловый менеджер» → папка `baikalst.ru` → «Загрузить файлы» → `baikal-site.zip` → правой кнопкой → «Распаковать». Заглушку из `public_html` удалите. Права доступа к файлам не меняйте и никогда не ставьте 777.
- **Домен:** «Домены и поддомены» → впишите `baikalst.ru` → «Направить домен на существующий сайт» → выберите сайт → «Добавить домены». NS-серверы Beget: `ns1.beget.com`, `ns2.beget.com`, `ns1.beget.pro`, `ns2.beget.pro`.
- **HTTPS:** «Домены и поддомены» → «Управление SSL сертификатами» → бесплатный сертификат Let's Encrypt → «Установить» (готов через 20–30 минут). Потом в окне шестерёнки сайта включите «Редирект с HTTP на HTTPS».
- **Если не загружаются большие фото:** в окне шестерёнки сайта откройте редактор директив PHP и добавьте две строки:

  ```
  upload_max_filesize = 16M
  post_max_size = 20M
  ```

## 6. Первый вход в админку

1. Откройте адрес сайта с `/admin` на конце, например `https://baikalst.ru/admin`.
2. Если администратора ещё нет, откроется страница «Настройка админки» — она попросит **защитный код**.
3. Код сайт кладёт в папку `data` — в файл, имя которого начинается с **SETUP_CODE** (например, `SETUP_CODE-3f9a1c2b7d4e.txt`). Откройте его в файловом менеджере хостинга (на своём компьютере — в папке проекта → `data`) и перепишите 8 цифр.
4. Придумайте логин (латинские буквы и цифры) и пароль — **не короче 10 символов**. Запишите их в надёжное место.
5. Нажмите кнопку — вы в админке. Файл с кодом удалится сам.

Зачем код: пока админка не настроена, кто угодно мог бы открыть `/admin` первым и занять её. Код видит только тот, у кого есть доступ к хостингу.

**Главная страница админки** показывает:

- **«Готовность к запуску»** и **«Перед запуском»** — что ещё заполнить, с кнопками перехода;
- **«Желательно»** — необязательные, но полезные пункты;
- **«Сервер и безопасность»** — версия PHP, обработка фото, HTTPS, защита папок. После загрузки на хостинг один раз нажмите «Проверить» у пункта про папку с картинками.

Вход защищён: после 5 неверных попыток вход с этого адреса блокируется на 15 минут. Если 8 часов ничего не делать в админке, нужно будет войти снова.

## 7. Домен baikalst.ru и защищённое соединение

Сейчас по адресу baikalst.ru открывается старый сайт. Чтобы открывался новый:

1. **Узнайте, где зарегистрирован домен.** Откройте cctld.ru/service/whois и введите `baikalst.ru`. Строка `registrar` — это регистратор (например, `REGRU-RU` — REG.RU, `RU-CENTER-RU` — RU-CENTER), `nserver` — где сейчас настроен домен, `paid-till` — до какого числа он оплачен.
2. **Добавьте домен на хостинге.** Timeweb: «Домены и SSL» → «Добавить домен» → `baikalst.ru` → привяжите его к сайту `baikalst.ru` → «Сохранить».
3. **Почта на домене.** Если у компании есть почта вида `…@baikalst.ru`, сначала перенесите её настройки (записи MX и TXT) в «Редактор DNS» нового хостинга — иначе письма перестанут приходить. Ящик BaikalSBTO@yandex.ru — обычная почта Яндекса, к домену он не привязан, его это не касается. Если сомневаетесь — напишите в поддержку хостинга, они помогут.
4. **Смените NS-серверы у регистратора** (в личном кабинете регистратора, в настройках домена). Для Timeweb: `ns1.timeweb.ru`, `ns2.timeweb.ru`, `ns3.timeweb.org`, `ns4.timeweb.org`. Изменения расходятся от 3 до 24 часов.
   - С 1 сентября 2026 года регистраторы просят подтвердить администратора домена через Госуслуги — без этого NS-серверы не поменять. Если регистратор попросит — пройдите подтверждение в его личном кабинете. Если домен оформлен на сотрудника или подрядчика, подтверждать должен он.
5. **Подключите бесплатный сертификат** — когда сайт уже открывается по адресу baikalst.ru. Timeweb: «Домены и SSL» → «SSL-сертификаты» → «Магазин сертификатов» → «SSL Let's Encrypt» → «Заказать» → выберите `baikalst.ru` → платную опцию «Настройка защищённого соединения» **выключите** → «Заказать». Готово через 5–10 минут, дальше сертификат продлевается сам.
6. **Включите переход на https:** «Сайты» → шестерёнка → «Перенаправлять на HTTPS» и «Включение протокола HTTP/2».
7. **В админке:** «Тексты, логотип, SEO» → вкладка «Поисковики и статистика» → «Адрес сайта»: `https://baikalst.ru` → «Сохранить».
8. Старый хостинг не отключайте ещё неделю — на всякий случай.

## 8. После запуска: Яндекс Вебмастер и Метрика

**Яндекс Вебмастер** — чтобы Яндекс быстрее нашёл новый сайт:

1. webmaster.yandex.ru → «Добавить сайт» → `https://baikalst.ru`.
2. Способ подтверждения — «Мета-тег». Скопируйте тег целиком.
3. В админке: «Тексты, логотип, SEO» → «Поисковики и статистика» → поле «Код подтверждения Яндекс Вебмастера» → вставьте тег → «Сохранить».
4. В Вебмастере нажмите «Проверить».
5. Там же: «Индексирование» → «Файлы Sitemap» → добавьте `https://baikalst.ru/sitemap.xml`.

**Яндекс Метрика** — чтобы видеть, сколько людей заходит на сайт и откуда:

1. metrika.yandex.ru → «Добавить счётчик» → адрес `baikalst.ru` → создать.
2. Скопируйте **номер счётчика** (только цифры).
3. В админке, на той же вкладке, поле «Номер счётчика Метрики» → «Сохранить».

Пока номер не указан, Метрика не подключается. Когда указан — на сайте появляется короткое уведомление о cookie.

**Яндекс Бизнес и Карты:** проверьте, что в карточке компании указан адрес нового сайта.

## 9. Что подготовить компании — чек-лист

Это знает только компания. Всё вносится в админке, а на её главной странице есть такой же список — с отметками, что уже готово.

**Обязательно перед запуском**

- [ ] **Автопарк** → «Автопарк». Сейчас там машины-примеры — замените их настоящими: модель, число мест, удобства (кондиционер, багаж, USB и т. п.).
- [ ] **Фото машин** — 3–6 на каждую: горизонтальные, при дневном свете, машина целиком, без людей и чужих номеров. Подойдут фото с телефона.
- [ ] **Ссылка на MAX** для кнопки «Написать» → «Контакты и мессенджеры». В приложении MAX: «Контакты» → «+» → «Пригласить по ссылке» → скопировать (ссылка вида `https://max.ru/u/…`). Лучше завести отдельный рабочий аккаунт диспетчера. Telegram и WhatsApp — по желанию.
- [ ] **Часы работы диспетчера** (или «круглосуточно») → «Контакты и мессенджеры».
- [ ] **Реквизиты** → «Реквизиты»: полное наименование, ИНН, КПП, ОГРН, юридический адрес, банк, БИК, расчётный и корреспондентский счета.
- [ ] **Вопросы и ответы** → «Вопросы и ответы». Ответы составлены заранее — проверьте каждый: оплата, договор, документы, за сколько дней заказывать.
- [ ] **Политика конфиденциальности** → «Тексты, логотип, SEO» → «Политика конфиденциальности». Прочитайте (лучше вместе с юристом) и отметьте, что проверили.
- [ ] **Техосмотр** → «Техосмотр»: список документов, часы работы станции, категории.
- [ ] **Адрес сайта** — после подключения домена (раздел 7, шаг 7).
- [ ] **Первая резервная копия** — после того как всё заполните (раздел 10).

**Желательно**

- [ ] **Цены** (за час, за километр, трансфер) → «Цены и калькулятор». Когда цены указаны, на сайте появляется калькулятор стоимости.
- [ ] **Цены техосмотра** — сейчас вместо них написано «Цену уточняйте».
- [ ] **Отзывы** → «Отзывы» — только настоящие и с согласия клиента. Пока отзывов нет, раздел на сайте скрыт.
- [ ] **Логотипы компаний-клиентов** (Газпром, Газартстрой, Краснодаргазстрой) → «Нам доверяют» — лучше с их согласия. Без логотипа показывается название.
- [ ] **Цифры о компании** (лет работы, машин в парке, поездок) → «Цифры о компании» — только реальные.
- [ ] **Логотип компании** (PNG, WebP или SVG) → «Тексты, логотип, SEO». Без него в шапке стандартный знак с названием.
- [ ] **Картинка для ссылок в мессенджерах** — сейчас стандартная, с названием компании и автобусом; можно заменить фото своего автобуса.
- [ ] **Точная метка на карте** → «Контакты и мессенджеры» → координаты офиса.
- [ ] **Яндекс Метрика и Вебмастер** (раздел 8).

## 10. Резервные копии

**Как скачать:** админка → «Резервная копия» → «Скачать резервную копию». Получится ZIP-архив со всем содержимым: тексты, автопарк, цены, контакты, учётная запись администратора и фото.

**Как часто:** раз в месяц и после больших изменений (новые машины, цены, фото). Храните копии у себя — на компьютере и в облаке (например, на Яндекс Диске), а не только на хостинге. Хостинг тоже делает свои копии (Timeweb — каждую ночь, хранит 30 дней), но своя копия надёжнее.

**Как восстановить сайт из копии:**

1. Распакуйте архив на компьютере (двойной щелчок по файлу).
2. В файловом менеджере хостинга откройте папку `data` и замените файл `site.sqlite` файлом из архива.
3. Загрузите содержимое папки `uploads` из архива в папку `public_html/uploads` на хостинге.
4. Откройте сайт и проверьте, что всё на месте. Логин и пароль от админки — те, что были на момент копии.

## 11. Забыли пароль от админки

1. В файловом менеджере хостинга откройте папку `data` и создайте в ней пустой файл с именем `RESET_PASSWORD` (без расширения).
2. Откройте страницу `https://baikalst.ru/admin/setup`.
3. Сайт попросит код: в папке `data` откройте файл, имя которого начинается с `SETUP_CODE`, и перепишите 8 цифр.
4. Задайте новый логин и пароль. Служебные файлы удалятся сами, а все, кто был в админке со старым паролем, из неё выйдут.

## 12. Если что-то не работает

| Что видите | Что делать |
|---|---|
| «Сайту нужен PHP 8.1 или новее» | В панели хостинга выберите PHP 8.4 или 8.3 (раздел 4, шаг 3). |
| «На хостинге не включены расширения PHP: …» | Напишите в поддержку хостинга: «Включите, пожалуйста, расширения PHP: …» — и перечислите их из сообщения. |
| Открывается заглушка хостинга вместо сайта | В папке `public_html` остался файл `index.html` — удалите его. |
| Ошибка 500 или пустая белая страница | Проверьте, что `app`, `data` и `public_html` лежат рядом, а `index.php` и `.htaccess` — внутри `public_html`. Сайт записывает ошибки в файл `data/logs/php-errors.log` — пришлите его программисту или в поддержку хостинга. |
| «Слишком много неудачных попыток» | Подождите 15 минут. Если забыли пароль — раздел 11. |
| Фото не загружаются, пишет «Файл слишком большой» | На главной странице админки появится пункт «Фото — не больше … МБ». Напишите в поддержку хостинга: «Увеличьте, пожалуйста, upload_max_filesize до 16M и post_max_size до 20M». На Beget это можно сделать самому (раздел 5). |
| В админке «Нет обработки картинок» или «Нет формата WebP» | Напишите в поддержку: «Включите, пожалуйста, расширение PHP GD с поддержкой WebP». |
| «Папка data открыта из интернета» | Папки `app` и `data` лежат внутри `public_html`. Перенесите их на уровень выше — рядом с `public_html` (раздел 4, шаг 5). |
| Нет новых заявок | Сайт сам заявки не получает: посетитель отправляет их сообщением или звонит. Проверьте телефон и ссылку на мессенджер в «Контакты и мессенджеры» и сами отправьте пробную заявку с телефона. |
| Не видно карты в разделе «Контакты» | Проверьте адрес офиса в «Контакты и мессенджеры» или укажите координаты. |
| Изменения из админки не видны на сайте | Обновите страницу: Cmd+R на компьютере, на телефоне — потяните страницу вниз. |

**Если хостинг не разрешает класть папки рядом с `public_html`.** На Timeweb и Beget это можно, на других хостингах так бывает редко. Запасной вариант — загрузить весь проект целиком в `public_html`: файл `.htaccess` в корне проекта направит посетителей в папку `public` и закроет `app` и `data`. Но на хостингах, где файлы отдаёт сервер nginx, эта защита может не сработать. Поэтому после загрузки обязательно откройте адрес `ваш-сайт/data/README.txt`: должна быть ошибка, а не текст. Если текст открылся — так оставлять нельзя: попросите поддержку хостинга разрешить папки рядом с `public_html` или выберите другой хостинг.

## 13. Обновление сайта и переезд на другой хостинг

**Обновление.** Если программист подготовит новую версию сайта, перед обновлением скачайте резервную копию. Обновление — это замена папок `app` и `public_html`, **кроме** папки `public_html/uploads` (там ваши фото). Папку `data` не трогать: в ней база со всем содержимым.

**Переезд на другой хостинг:**

1. Скачайте свежую резервную копию (раздел 10).
2. На новом хостинге загрузите сайт (раздел 4).
3. Замените `data/site.sqlite` и содержимое `public_html/uploads` файлами из копии (раздел 10).
4. Перенесите домен и подключите сертификат (раздел 7).

## 14. Безопасность

**Что уже сделано на сайте:**

- Пароль от админки хранится только в зашифрованном виде. После 5 неверных попыток вход блокируется на 15 минут.
- Все формы админки защищены от подделки запросов, все данные на страницах выводятся безопасно.
- Загруженные фото пересохраняются в формат WebP: из них удаляются скрытые данные (например, геолокация), файлам даются случайные имена. SVG-логотипы очищаются от скриптов.
- В папке с фото запрещён запуск программ — админка может это проверить кнопкой «Проверить».
- Программа и база данных лежат вне папки, открытой из интернета.
- Сайт не собирает персональные данные посетителей: заявка уходит из браузера посетителя прямо в мессенджер или по телефону.

**Что нужно от вас:**

- Пароль от админки — длинный и нигде больше не используемый. Не пересылайте его в мессенджерах.
- Пароль от панели хостинга — тоже. Если хостинг предлагает вход с подтверждением по SMS или через приложение — включите.
- Скачивайте резервную копию раз в месяц.
- Если сайтом займётся программист — дайте ему отдельный доступ к хостингу (у Timeweb: «Пользователи ПУ/FTP»), а не свой пароль.

## 16. Для программиста

- **Стек:** PHP 8.1+ без фреймворка и Composer, SQLite через PDO, обычные CSS и JS-модули без сборки, свои шрифты Manrope (woff2, кириллица).
- **Точка входа** — `public/index.php` (он же роутер для `php -S`). Маршруты — `app/routes.php`, обработчики страниц — `app/pages`, шаблоны — `app/views`, общие функции — `app/lib`, логика админки — `app/admin`.
- **База** создаётся при первом запросе: схема — `app/lib/schema.php`, начальные данные — `app/lib/seed.php` (машины-примеры помечены `is_demo = 1`, вопросы FAQ — `needs_review = 1`).
- **CSS** встраивается в страницу (`inline_css()`), сжатая версия кэшируется в `data/cache` по времени изменения файла. JS подключается с `?v=` по времени изменения.
- **Локальный запуск без Docker:** `php -S 127.0.0.1:8000 -t public public/index.php`. С Docker — см. `Запустить сайт.command` и образ `.claude/php.Dockerfile`.
- **Режим отладки** (подробные ошибки, страница `/styleguide`) включается только во встроенном сервере PHP (`php -S`).
- **Безопасность:** CSRF-токен на всех формах, prepared statements, экранирование вывода, сессия HttpOnly + SameSite=Lax (+ Secure при HTTPS, в том числе за прокси: `X-Forwarded-Proto`, `X-HTTPS` у Timeweb), ограничение попыток входа (5 за 15 минут), проверка MIME через finfo, пересохранение картинок в WebP без EXIF, очистка SVG, запрет PHP в `uploads` (`.htaccess` + проверка из админки), код первой настройки в файле со случайным именем.
- **Резервная копия** собирается «на лету»: снимок базы через SQLite backup API или `VACUUM INTO`, ZIP пишется своим кодом прямо в ответ сервера (расширение zip не нужно), на сервере архив не хранится.
- **Архив для хостинга** — `Собрать архив для хостинга.command`: копирует `app`, `public` → `public_html`, делает копию базы через `sqlite3 .backup` и пропускает служебные файлы `data` (сессии, кэш, журналы, коды входа).
